# Simulation of Robotic Systems

## Description
A project written in Python using PyCharm and CoppeliaSim Edu v4.9.0 (on Windows 10).
Should work on other IDEs/OSs.

## Usage
PracticalExercise1_BubbleRob.pdf explains how to start the programs. It requires both the CoppeliaSim scene file to be open and the python script(s) in an IDE of your choice.
